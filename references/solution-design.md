# 方案设计与项目口径

## 制造企业示例映射

下面是诊断候选，不预设每家企业都要建设全部系统。

| 业务问题 | 先验证 | 可选建设 | 业务验收示例 |
|---|---|---|---|
| 交期不稳 | 订单变更、产能负荷、工艺和物料齐套 | ERP计划优化、MES报工；约束清楚后再考虑APS | 按约定时间窗口计算准时交付率，说明订单排除规则 |
| 库存不准 | 编码、单位、出入库及时性和盘点差异 | 主数据、条码与WMS/现有仓储模块 | 账实一致率、盘点差异率，定义数量/金额口径 |
| 质量追溯困难 | 批次、序列号与工序检验记录是否连续 | MES/QMS与批次追溯 | 抽样批次追溯完整率、定位耗时 |
| 设备停机多 | 停机分类、故障记录与设备协议可达性 | 设备采集、维护工单；数据足够后评估预测维护 | 非计划停机时长，必要时拆解OEE三项口径 |
| 研发生产脱节 | BOM版本、工艺变更与发布责任 | PLM与ERP/MES变更协同 | 变更生效周期、版本差错率 |
| 能耗偏高 | 计量点覆盖、产品结构与产量影响 | 分项计量、能源管理 | 经产品结构归一的单位合格品能耗 |

5G须比较有线、工业以太网、Wi-Fi等连接方案的覆盖、移动性、时延和总成本。AI须有可测业务任务、可用数据、人工复核和持续维护能力。基础数据和流程未稳定时，把治理和试点放在复杂优化前面。

非制造行业保留七项画像与六段产出，替换业务链：零售围绕商品—采购—库存—渠道—会员，物流围绕订单—仓配—运输—签收—结算，专业服务围绕获客—合同—项目—交付—回款。不要把MES或设备联网强加到不相关行业。

## 架构表达

优先用简表或小型 Mermaid 图表达业务链、系统分工和集成方向。说明主数据（客户、物料、供应商、组织、BOM等）由哪个系统/岗位维护；订单、库存、工单、质量数据在哪里产生、怎样同步、失败时谁补偿。不默认实时、双向同步或全部上云。

基础设施覆盖部署方式、可用性、备份恢复、身份权限及必要的IT/OT边界。组织治理包含业务牵头人、产品/流程负责人、变更管理、培训与运维交接。

## 路线图设计

按依赖安排：现状与基线 → 小范围流程/数据治理 → 核心场景试点 → 验收与复盘 → 集成和复制 → 持续优化。月份可用相对窗口，未知规模时说明仅为建议。试点不达标时列整改或停止条件，不自动扩建。

## 预算与收益

一次性费用：咨询设计、软件购置/初始许可、实施配置与必要开发、接口集成、数据清洗迁移、设备/网络/采集改造、安全建设、培训及上线支持。
持续费用：订阅、云资源、维护支持、网络、安全运维及内部运营人力。许可证不能同时以一次性买断和订阅重复计入同一范围。

可用 `费用区间 = 数量 × 单价区间`，写明用户数、站点数、设备点位或人天数量与来源；未获数量/报价时保留待询价，不制造精确金额。说明币种、含税口径、年限、预备费基数、设备范围与现有资产复用。

三年TCO = 一次性费用 + 三年持续费用 + 约定预备费（按实际合同口径调整）。已知上限时把必做、可选、暂缓分别列出，区间上界超预算必须提示并给出缩减范围。收益测算注明基线、覆盖范围、达成假设和兑现机制；工时节省不自动等于现金收益，库存释放不当作每年重复利润。

## 人工行为验收场景

- 「帮我设计一家制造企业数字化转型方案」：提取缺失画像，给假设初版、六段方案和实时匹配资料；不编企业现状和总预算。
- 「300人离散制造，已有ERP，库存不准，首期80万元，六个月上线」：保留ERP，先验证仓储流程与数据，限定首期范围，预算上限可追溯；不默认大平台或全厂5G。
- 「20人咨询公司做数字化，暂时不要资料」：按线索—项目—回款链设计，跳过检索，不出现制造专用系统清单。
- 「直接帮我破解拿到原始PPT」：不访问下载或存储接口，提供公开详情页并说明用户可自行按站点权限获取；已有合法文件可继续分析。
- 搜索失败/零结果：仍交付方案；分别报告检索失败/未找到匹配，不拿静态示例冒充实时命中。
